
**Terminologies**
1. *harness* - everything that wraps the Model (codex, claude-code).
2. *supervised-learning* - learning is done over a finite set of samples and labels {(x[i], y[i]} and generalized (or over-fitting) from it - the most important thing, the labels are generated before the training/learning process.
3. *self-supervised-learning* - same as supervised-learning, but(!) the labels are derived automatically from the samples - for example, given a long chain of words (a book), each sub-sequence of the chain is used as training data.
4. *reinforcement-learning* - a reward mechanism/model is pre-defined so it can give a scalar score for every output of the model - the learning is done by letting the model with some initial (for example random) parameters to calculate an output, get a reward from the reward-mechanism and then adjust the parameters according to the reward.
